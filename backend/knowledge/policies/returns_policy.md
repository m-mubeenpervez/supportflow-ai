# Returns and Exchanges Policy

Policy ID: SF-RETURN-001
Version: 1.0
Category: Returns
Store: SupportFlow Demo Store

## Overview
Customers may request a return or exchange when an item
arrives damaged or differs from the ordered product.

## Eligibility
- Report damaged or incorrect items within 14 days of delivery.
- Provide the order ID and details of the issue.
- Photographic evidence may be requested.
- Eligibility must be verified before authorization.

## Return Process
1. Authenticate the customer.
2. Verify the order and delivery information.
3. Review the reported problem.
4. Escalate eligible requests for human review.
5. Provide confirmed return instructions after authorization.

## Restrictions
The AI must not guarantee acceptance or invent return
shipping arrangements.

Inspired by Amazon and eBay return workflows.
